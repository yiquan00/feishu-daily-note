# 飞书日记

一款以飞书多维表格为同步目标的 Android 日记应用。日记先保存在手机本地；配置飞书后，应用可以把记录写入多维表格，并从表格读取记录。

## 主要功能

- **写日记**：记录正文和日期，可添加“生活”“工作”“学习”标签、照片（单次选择最多 9 张），以及当前位置或手动输入的位置。
- **浏览与查找**：按标签切换列表，搜索日记正文、标签和位置；支持查看、编辑、长按删除。
- **本地保存**：未配置飞书时也能写日记，记录保存在设备上。
- **飞书同步**：配置完成后，保存、修改和删除日记时调用飞书接口；可下拉刷新或在设置页手动执行同步，并查看同步状态。
- **桌面小组件**：显示日记及同步状态，可按标签筛选、随机切换一篇。
- **外观与访问**：支持跟随系统、浅色、深色主题；可开启系统安全锁，进入应用时使用设备密码或指纹验证。

## 飞书配置

### 1. 创建飞书应用

1. 登录[飞书开放平台](https://open.feishu.cn/)，创建**企业自建应用**。
2. 在应用的“凭证与基础信息”中找到 **App ID** 和 **App Secret**。
3. 在“权限管理”中开通多维表格记录所需的 `bitable:app` 权限，并发布应用版本。若照片上传提示权限不足，还需按飞书报错补充文件上传相关权限。

请妥善保管 App Secret，不要把真实凭据写进代码、截图或提交到 Git 仓库。

### 2. 创建多维表格

新建一个飞书多维表格，在其中建立数据表，并使用以下**完全一致**的字段名：

| 字段名 | 字段类型 | 用途 |
| --- | --- | --- |
| 日记 | 文本 | 日记正文；建议作为主字段 |
| 日记日期 | 日期 | 日记时间 |
| 标签 | 多选 | 选项：生活、工作、学习 |
| 定位 | 文本 | 地址或手动输入的位置 |
| 照片 | 附件 | 日记照片 |

> **定位字段请选择“文本”**。当前同步代码向它发送的是地址字符串，并非飞书的地理位置对象。

在多维表格的应用授权设置中，将刚创建的自建应用添加为可访问该表格的应用。

### 3. 获取表格标识

从多维表格链接中获取：

- **App Token / Base ID**：链接中 `/base/` 后面的 `bascn...` 部分。
- **Table ID**：链接参数 `table=` 后面的 `tbl...` 部分。

例如，链接形式为 `https://你的飞书域名/base/bascn示例?table=tbl示例`。这里的“示例”只是格式说明，请填写你自己的标识。

### 4. 在应用内连接

进入 **应用设置与配置 → 飞书多维表格参数配置**，填入 App ID、App Secret、App Token 和 Table ID。先点击**测试连接**；成功后点击**保存配置**，再点击**立即查询同步**，或返回首页下拉刷新。

如果测试失败，请依次检查四项标识、应用权限与版本是否已发布，以及多维表格是否已授权给该应用。


## 技术实现

项目使用 Kotlin、Jetpack Compose 和 Room；通过飞书开放平台的多维表格 API 同步日记，使用 Android 桌面小组件展示记录。最低支持 Android 7.0（API 24）。
